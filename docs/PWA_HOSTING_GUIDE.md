# Руководство по развёртыванию PWA для iPhone (Safari) и Android

## Почему требуется серверная часть (Backend)

Фронтенд NEXUS Media работает как Progressive Web App (PWA) с автономной оболочкой (`Service Worker` + `manifest.webmanifest`), но **обработка медиапотоков, извлечение разрешений (`yt-dlp`), перекодирование видео/аудио (`FFmpeg`) и защита от SSRF не могут выполняться внутри браузера iOS Safari**.

Поэтому для работы приложения на iPhone или Android необходим доступ к серверу FastAPI (`/api/*`).

---

## Сценарий 1: Тестирование в домашней локальной сети (Wi-Fi)

1. Узнайте локальный IP вашего компьютера с CachyOS в сети Wi-Fi:
   ```fish
   ip -4 addr show | grep inet
   ```
   *(например, `192.168.1.50`)*

2. Для полноценной установки PWA и работы Service Worker в iOS Safari требуется **HTTPS** (Safari разрешает Service Worker без HTTPS только на `localhost`).
   Самый быстрый способ поднять локальный HTTPS с доверенным сертификатом — `mkcert` или `caddy`:
   ```fish
   # Вариант через Caddy (автоматический локальный TLS):
   caddy reverse-proxy --from https://192.168.1.50:8443 --to http://127.0.0.1:5173
   ```

3. Откройте адрес в Safari на iPhone → нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.

---

## Сценарий 2: Доступ за пределами домашней сети (Удалённый доступ)

> **Важно (Безопасность):** Не открывайте сервер NEXUS Media в публичный интернет без аутентификации, чтобы он не использовался посторонними как открытый прокси-загрузчик.

Рекомендуемые безопасные способы подключения с собственного iPhone вне дома:

1. **Tailscale / WireGuard VPN (Рекомендуется):**
   - Установите Tailscale на домашний Linux-компьютер и на iPhone.
   - Включите `tailscale serve --https=443 http://127.0.0.1:8000` (со статической раздачей `frontend/dist`).
   - Вы получаете валидный HTTPS-сертификат (`*.ts.net`), доступный **только вашим устройствам** без публикации сервиса в открытый интернет.

2. **Cloudflare Tunnel с Cloudflare Access (Zero Trust):**
   - Защитите домен политикой `Cloudflare Access` (вход по одноразовому PIN на ваш email).
   - Проксируйте трафик на локальный порт NEXUS Media.
